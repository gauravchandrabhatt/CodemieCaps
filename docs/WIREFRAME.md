# Wireframe

```text
┌───────────────────────┬──────────────────────────────────────────────────────────────┐
│ CodemieCaps           │ Workspace / Capstone SDLC Demo                         (G) │
│                       ├──────────────────────────────────────────────────────────────┤
│  Overview             │ SDLC Cockpit                  [DEMO WORKFLOW ACTIVE]        │
│  SDLC workflow        │ Backlog items | Needs your review | Phases approved          │
│  Backlog              ├──────────────────────────────────────────────────────────────┤
│  Audit trail          │ Assistant workflow                                           │
│                       │ [01 Analysis] [02 Planning] … [08 Documentation]              │
│ Local demo · SQLite   │ Active phase artifact editor · reviewer note                 │
│                       │                           [Request changes] [Approve phase]   │
│                       ├──────────────────────────────┬───────────────────────────────┤
│                       │ Enhancement backlog          │ Recent activity / audit trail │
└───────────────────────┴──────────────────────────────┴───────────────────────────────┘
```

On narrow screens, the navigation and stage list become compact, and the backlog/activity panels stack vertically. The review card labels whether its artifact is a draft or is awaiting a human decision. The audit panel is read-only.
